# Novareach — Software Company Website

A premium, animated React + Vite marketing site built with Tailwind CSS, Framer Motion, Lucide icons and Swiper.

## Getting started

```bash
npm install
npm run dev       # start local dev server
npm run build      # production build to /dist
npm run preview    # preview the production build
```

## Structure

- `src/components` — reusable sections (Navbar, Hero, Services, Solutions, Process, Portfolio, Testimonials, CTA, Footer, etc.)
- `src/pages` — Home, About, Services, Contact
- Routing via `react-router-dom`

## Pages

- `/` — Home (hero, trust strip, about preview, services, solutions, why-us, tech stack, process, portfolio, testimonials, CTA)
- `/about` — Story, mission, vision, values, leadership, stats, careers
- `/services` — 12 detailed services with alternating layout
- `/contact` — Contact info + enquiry form + map
